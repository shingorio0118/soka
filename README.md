# 草加駅前 ドット絵マップ (Soka Station pixel-art walkable map)

草加駅 (埼玉県草加市) 周辺、東西 810 m x 南北 960 m を、ポケモン風の 2D ドット絵で歩けるようにした、
フロントエンドだけの静的サイトです。サーバー処理・外部通信はありません。

## 遊び方

    python3 -m http.server 8765
    # ブラウザで http://127.0.0.1:8765/ を開く

- PC: 矢印キー / WASD。`M` キーで全体地図。
- スマホ縦持ち: 画面下の四角い十字ボタン。右上の四角いボタン「地図」で全体地図 (もう一度押すと閉じる)。全体地図の間は歩けません。
- 建物・線路・水面・街灯・のぼり・駐輪ラックには入れません。
- 駅の東西通路 (OSM の building_passage / corridor) と、線路の高架の下をくぐる道は通れます (下記)。
- 右上に今いる場所の名前が出ます。お店・施設のすぐそば (建物の輪郭から約 2 タイル以内) では、その店名 (1 行目) と分類・エリア名 (2 行目) です。離れると、これまでどおりエリア名 (駅・出口・公共施設・通り・商店街) だけです。
- 近くのお店・施設には名札 (クリーム色の四角い札と分類色の帯) が出ます。7 タイル以内の近い順、スマホ縦で最大 7 枚 (PC は 12 枚)、札どうしと自キャラは重ならないよう位置をずらし、置けないものは出しません。近くに何もない所では出ません。
- 地図ボタンの全体地図には、お店・施設を分類色の四角い点で表示します。下 (横長画面は右) の分類ボタン (コンビニ・買い物・飲食・カフェ・金融郵便・医療薬局・公共学校・寺社公園史跡・サービス娯楽) を押すと一覧が出て、名前を押すと地図上で赤枠で示します。地図の点を押しても選べます。
- `?debug` を付けると `window.__soka.teleport(x, y, dir)` が使えます (テスト用)。

## 範囲と縮尺

- 1 タイル = 3 m、タイル画像 16x16 px、マップ **270 x 320 タイル** (東西 810 m x 南北 960 m)
- 範囲は駅ノード (id 7481965874) を (0, 0) として、東西 -390 m ～ +420 m、南北 -480 m (北) ～ +480 m (南)。駅は西寄りに置き、東側 (商店と日光街道側) を広めに取っています。
- 表示は整数倍 (スマホ 3 倍 x 画面密度、PC 4 倍)、`image-rendering: pixelated`
- 軽量化: マップは `assets/map.json` に連長圧縮 (約 350 KB、gzip 約 65 KB)。描画は画面に入っているタイルだけを毎フレーム描き、巨大な事前描画キャンバスは使いません。

## データ -> マップの流れ

1. `tools/fetch_osm.py` : OpenStreetMap API 0.6 `/map` を小さな範囲 (16 リクエスト) に分けて取得し、id で重複を除いて統合 (範囲 東西 -470～+480 m、南北 -540～+540 m。余白込み)。
   取得 XML (投稿者名を含む) はリポジトリに置かず `/tmp/soka_osm_xml` にキャッシュ (`--cache DIR` で変更)。
   個人情報を避けるため、住所・番地・電話・メール・ウェブサイト・ユーザー名は保存しません。必要なタグだけ残します。
   `elements` (地形・建物・道) の名前は駅・出口・路線名・通り名・公共施設・主要な大型店だけです。
   お店・施設の名札用の名前は別の `pois` 配列に、名前・分類・位置だけを保存します (下記「お店・施設の名前」)。結果: `data/osm_raw.json` (約 670 KB)
2. `tools/make_art.py` : Pillow で全アートを生成 (`assets/tiles.png`, `tiles.json`, `player.png`, `sign_soka.png`)。ポケモンや実在ロゴは使っていません。
3. `tools/build_map.py` : OSM を 3 m グリッドに変換して `assets/map.json` と `assets/signs.png` (通り名の看板) と `data/build_report.json` (範囲・到達性・踏切相当・商店街の検出結果) を作成。
4. `tools/render_overview.py out.png [倍率] [--solid] [--crop x0,y0,x1,y1]` : 全体図を PNG にします (確認用。`--solid` で入れない場所を赤く塗る)。
5. `tools/e2e/e2e.js [出力先]` : puppeteer-core による動作確認 (キー移動、衝突、線路下の通り抜け、商店街の歩行、D-pad タッチ、地図ボタン、フレームレート、横スクロールなし、コンソールエラーなし、スクリーンショット、名札: 名前データの検査・店のそばの店名表示・名札の上限と重なりなし・何もない所で名札が出ない・全体地図の分類一覧と選択)。

    python3 tools/fetch_osm.py && python3 tools/make_art.py && python3 tools/build_map.py
    python3 -m http.server 8765 --bind 127.0.0.1 &
    NODE_PATH=/path/to/node_modules node tools/e2e/e2e.js /tmp/shots

## 手直し (data/overrides.json、任意)

`{"set":[{"x":列,"y":行,"base":"タイル名","deco":"タイル名","over":"タイル名","solid":true}]}`
座標は完成したマップのタイル座標 (0..269, 0..319)。`base` / `deco` / `over` / `solid` は書いたものだけ上書きします。タイル名は `assets/tiles.json` にあります。
`build_map.py` を再実行すると反映されます。

## 線路と踏切 (仮定)

- OSM では東武伊勢崎線が草加駅の前後 数 km にわたりすべて `bridge=viaduct` (高架) で、`level_crossing` は 1 つもありません。そのため踏切は作っていません。
- 高架と線で交差する道・歩道 (ノードを共有しないもの) は「高架の下をくぐる」と解釈し、交点の前後約 9 タイルだけ暗い影の付いた歩ける道 (`under_*`) にしています。
  結果は 5 本 (北から: 無名の道 y=-330 m、無名の住宅街の道 y=-215 m、歩道 y=+128 m、**草加神社通り y=+198 m**、無名の道 y=+352 m)。
  線路に並行する道は通り抜けにはしません。
- 駅の下の東西通路は OSM の通路データに基づきます。

## 商店街 (仮定)

- OSM には 草加駅前の「商店街」「アーケード」「歩行者専用道」の名前・タグがありません (遊歩道タグも無し)。
  そのため **店 (shop / 飲食 / 銀行など) の分布から商店街らしい道を自動検出** しています (道から 15 m 以内に店が 2 軒以上あり、一定の長さがある道)。
- 検出した道は、レンガ敷きの歩行者風の路面にし、道沿いの建物の店に縞のひさし (6 色) と店先 (窓・扉・看板帯) を付け、街灯 (提灯風)・のぼり旗・駐輪ラックを置きます。
- 通り名が OSM に無いので、看板と場所名は名前を作らず一般名の「商店街」のみです。実在の名前が OSM に入れば自動でその名前になります。
- 店の位置 (店名なし) は OSM の店ポイントが元です。OSM が未入力の店は反映されず、実際より少なく見えます。

## お店・施設の名前 (名札)

- 元データは OSM の `name` (`name:ja` があればそちら) です。`tools/fetch_osm.py` の `extract_pois()` が、公開された店・飲食店・病院・薬局・銀行・郵便局・学校・公共施設・寺社・公園・史跡・娯楽施設だけを `data/osm_raw.json` の `pois` に残し、`tools/build_map.py` が `assets/map.json` の `pois` (x, y, 名前, 分類, 優先度, 建物の外形) と `poiCats` (分類名・色) にします。
- 分類は 9 つ: コンビニ / 買い物 / 飲食 / カフェ / 金融・郵便 / 医療・薬局 / 公共・学校 / 寺社・公園・史跡 / サービス・娯楽。
- **プライバシー (公開リポジトリ)**: 次は保存前に捨てます。個人名らしい名前 (姓だけ、名前らしい語尾、〇〇家・〇〇邸、持ち主の名前のビル)、住宅 (building=house 等、landuse=residential)、`access=private` や閉店・廃止の印、住所・番地らしい名前 (数字-数字、町名+番号)、1 文字や 31 文字以上の名前、葬儀社・警備・職人 (craft) などの個人色が強い分類、駐車場・駐輪場・自販機・ATM・ベンチ。捨てた件数だけを `data/build_report.json` の `pois.dropped_by_reason` に残し、捨てた名前は一切保存しません。電話・メール・ウェブサイト・住所・投稿者名・uid・changeset は元から読みません。迷ったら捨てる方針です。
- 同じ店が点 (ノード) と建物の両方に入っている場合は、同名で 30 m 以内なら 1 つにまとめます。
- OSM の名前は不完全です。実際にある店でも名前が OSM に無ければ出ません。位置も点の場所なので、店先の向きとは合わないことがあります。多数のテナントが入る建物 (VARIE など) は名札が積み重なります。

## 仮定と注意

- 駅の線路はすべて高架として描画し、補助線 (側線・留置線) は線路でなく床として単純化しています。
- 駅ビル (VARIE) と線路・ホームを 1 つの「高架駅」領域として扱い、通路タイルだけが歩けます。
- 街灯は一部 OSM のデータではなく、道路沿いに自動配置した装飾です。
- 3 m グリッドのため、細い道や歩道は実際の幅と一致しません。
- 範囲の北西・南西など OSM に建物が少ない所は、空き地に見えます。
- 到達性: スポーン地点から歩けるタイルの 99.5 %。残り (約 350 タイル) は、線路・建物・塀の間にできた細長い隙間 (幅 1 タイル、周りを建物で囲まれた所) などです。詳しくは `data/build_report.json` の `cut_off_areas`。
